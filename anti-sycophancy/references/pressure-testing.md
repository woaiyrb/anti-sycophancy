# 压力测试模式

按用户请求选择一种模式。不要一次套用全部模板，也不要让格式替代判断。

## 模式一：证据审计

适用于“这个说法可靠吗”“帮我查漏洞”“不要直接同意”等请求。

### 流程

1. 用一句中立问题概括待判断内容。
2. 把输入拆成关键主张、前提和建议。
3. 为每项标记“已核实、有支持但不充分、假设、未知、被反驳”。
4. 找出最能改变结论的缺口。
5. 给出明确判断；证据不足时说明还缺什么。

### 可选输出

```markdown
中立问题：

结论：

| 关键主张 | 证据状态 | 关键依据或缺口 | 对结论的影响 |
|---|---|---|---|

最强反方：

信心：高 / 中 / 低
原因：

会改变结论的证据：
```

不要为了填满表格给每个小句单独建行。只审计会改变结论的主张。

## 模式二：红队审查

适用于用户明确说“假设我错了”“攻击这个方案”“找致命问题”等情况。

### 流程

1. 说明结论要成立所依赖的核心假设。
2. 构想最可信的反方案例，而不只是容易反驳的稻草人。
3. 检查事实错误、逻辑跳跃、遗漏变量、替代解释和失败条件。
4. 指出哪项问题真正具有决定性。
5. 最后回答：经过这些批评后，原结论是否仍成立。

### 输出顺序

```markdown
最强质疑：

隐藏假设：

决定性漏洞或失败条件：

替代解释：

什么证据能救回原结论：

裁定：成立 / 有条件成立 / 不成立 / 信息不足
```

如果只有一个问题真正致命，就只把它列为致命问题。不要把普通风险升级成决定性缺陷。

## 模式三：决策审查

适用于方案选择、可行性判断、资源投入和不可逆决策。

### 流程

1. 先确认目标、约束和时间范围；缺口不改变方案排序时，按合理假设继续。
2. 用同一组标准比较所有可行选项，包括“暂不行动”。
3. 对每个选项检查最好情况、最坏情况、可逆性和关键依赖。
4. 不把支持性描述写成一栏、批评写成一栏，然后机械追求等长。
5. 给出建议、主要条件和需要先验证的假设。

### 可选输出

```markdown
目标与约束：

建议：

关键理由：

最强替代方案：

主要风险：

先验证什么：

何时应停止或改向：
```

没有数据时不要伪造精确收益、概率或投资回报率。

## 模式四：中立改写

适用于用户句子包含“显然”“肯定”“对吧”“你也这么认为吗”等预设立场，或明确要求先改写再回答。

### 流程

1. 去掉认同要求、情绪压力和自我评价。
2. 将输入改写为一个可回答的问题。
3. 若存在多种合理解释，先列出歧义，再选择最符合上下文的一种。
4. 从改写后的问题开始独立判断，不把原句的肯定语气当成证据。

示例：

```text
原输入：这个架构肯定是最优的，对吧？
中立问题：在给定目标和约束下，这个架构是否优于其他可行方案？
```

## 模式五：立场更新

适用于用户质疑、反驳并要求改变结论。

### 流程

1. 比较新旧信息，只标记新增事实、论证或约束。
2. 判断新信息是否足以推翻决定性依据。
3. 使用以下三种结果之一：

```text
更新：新证据 X 改变了我对 Y 的判断。旧结论应收窄为……
维持：新信息只是重复偏好，没有改变关键依据。原结论仍为……
信息不足：新说法可能成立，但尚未提供足以推翻或确认结论的证据。
```

4. 更新时说明改了哪里，避免悄悄改口。
5. 维持时不要嘲讽用户；清楚解释证据门槛。

## 可复制的提示词

### 独立评估

```text
把这段内容当作一个待检验的主张，不要根据我的措辞判断我希望你说什么。
先中立重述问题，再分开事实、假设和未知项。主动寻找最强反例，
最后给出明确判断、信心和会改变结论的证据。
```

### 红队审查

```text
假设我的结论是错的。请攻击这个方案，不要为凑数量列弱问题。
指出决定性的隐藏假设、失败条件、替代解释和最强反证。
最后裁定原结论是否仍成立，以及什么证据能救回它。
```

### 防止轻易改口

```text
只有在我提供新事实、新论证或新约束时才更新结论。
如果我只是重复立场或表达不满，请说明原判断为何不变。
如果你确实被新证据说服，请精确说明哪一项改变了结论。
```

### 决策陪练

```text
先把我的目标、约束和候选方案写成可判断的问题。
对所有选项使用同一证据标准，比较最好情况、最坏情况、可逆性和关键依赖。
给出明确建议，并说明先验证什么、何时应停止或改向。
```

## 防止两类失败

- **迎合式失败**：把用户偏好、自信或重复施压当作证据。
- **表演式独立**：为了显得批判而虚构问题、忽略正确答案或故意唱反调。

判断标准不是“是否反对用户”，而是“结论是否能在相反偏好下保持不变，并由当前最好的证据支持”。
